# JustDump

Website for **JustDump**, an iPhone app that turns what you say into Apple Reminders, privately and on-device with Apple Intelligence.

- Privacy policy: https://ythknn.github.io/justdump/privacy/
- Support: https://ythknn.github.io/justdump/support/
